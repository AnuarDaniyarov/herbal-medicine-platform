# Предварительный аудит данных по ацетилхолинэстеразе

Дата проверки: 13 октября 2026 г.

## Цель

Проверить, можно ли построить учебный ML-прототип для ранжирования растительных соединений по ингибированию человеческой ацетилхолинэстеразы (AChE). Это предварительный аудит, а не окончательное утверждение научной задачи.

## Использованные данные

- Таблицы IMPPAT 3.0: `Bioactivity_IMPPAT_Phytochemicals.tsv` и `Chemical_Information_IMPPAT_Phytochemicals.tsv`.
- Дополнение к статье Cortés-Ciriano et al.: `7068968.zip`, внутри `ci8b00376_si_003.zip`, затем `Datasets/Acetylcholinesterase.sdf`.
- В SDF находятся ChEMBL ID и усреднённый pIC50. В статье наборы ChEMBL 23 отбирались по точному IC50 (`=`), нМ, белковой мишени типа SINGLE PROTEIN и организму Homo sapiens; при нескольких значениях авторы усредняли pIC50.

| Точные совпадения IMPPAT по полному InChIKey | 48 |
| Дополнительные точные InChIKey совпадения сверх ChEMBL ID | 2 |

| Проверка актуального ChEMBL | Результат |
| --- | ---: |
| Измерения в ChEMBL | 7 646 |
| Уникальные ChEMBL соединения | 6 134 |
| Совпавшие по ChEMBL ID соединения IMPPAT | 93 |
| Измерения для этих 93 соединений | 281 |
| Различные assay среди прямых совпадений | 168 |
| Документы/публикации среди прямых совпадений | 157 |
| Точные совпадения по полному InChIKey, включая записи без ChEMBL ID в IMPPAT | 100 |
| Дополнительные точные совпадения через InChIKey | 7 |
| Из 100 соединений с согласованной стороной порога | 48 с pIC50 ≥ 5, 46 с pIC50 < 5 |
| Соединения с результатами по обе стороны порога в разных assays | 6 |

У 7 новых InChIKey-сопоставлений найдено по одному измерению в выбранной выдаче; после их добавления итоговая выборка содержит 100 растительных соединений. У 6 соединений из 93 прямых совпадений измерения в разных assays переходят через порог pIC50 = 5. Их метки нельзя фиксировать до просмотра assay и публикаций. Для остальных 94 соединений значения по выбранному порогу не расходятся: 48 выше/равно порогу активности и 46 ниже.

Порог pIC50 = 5 соответствует IC50 = 10 мкМ. Разделение 38/10 показано только для предварительной оценки баланса классов; сам порог требует научного обоснования.

В исходной таблице биоактивности IMPPAT обнаружено 125 записей для AChE человека по IC50. Простая очистка оставляет 68 соединений с одним различимым значением в нМ без явных цензурированных значений (`<`, `>`) и без конфликтующих чисел. Это число предварительное: исходные значения разных источников собраны в одной ячейке, поэтому для окончательной разметки нужно проверять первичные записи и условия анализа.

## Вывод

Дополнение к статье содержит 3 159 записей по всем соединениям, а не только по веществам растений. В актуальном ChEMBL найдено больше измерений; после точного сопоставления по полному InChIKey выборка растёт до 100 растительных соединений. Для пробного baseline это уже пригодный небольшой набор, но он остаётся слишком малым для сильных заявлений о переносимости и качестве модели. Из 100 соединений 94 имеют согласованные метки при предварительном пороге 10 мкМ; ещё 6 требуют разрешения конфликтующих результатов.

Совпадения лишь по первой части InChIKey нельзя автоматически считать одинаковыми молекулами: так могут совпасть соединения с разной стереохимией. Их следует отдельно проверять по полной структуре.

## Следующий шаг

Сохранить assay ID, описание, документ и первичное значение; изучить шесть неоднозначных соединений и зафиксировать правило обработки повторов. Затем сформировать версионированную таблицу для baseline, проверить точные и близкие дубликаты структуры и выполнить разделение на train/test по scaffold или кластеру, чтобы уменьшить утечку похожих молекул.
